A library written in Zig that provides a native implementation of the D-Bus protocol.<br> 
It allows you to connect to the D-Bus system or session bus, send and receive messages, handle signals, and introspect D-Bus objects.

## Installation

You can add `plume` to your project using `zig fetch`:

```bash
zig fetch --save https://codeberg.org/erffy/plume/archive/0.17.x.zip
```
